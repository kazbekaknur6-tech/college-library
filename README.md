 Колледж кітапханасының веб-сайты

 Жобаның мақсаты
Колледж кітапханасының кітаптары мен пайдаланушылары туралы ақпаратты басқаруға арналған веб-жоба.

Қолданылатын технологиялар
- PHP 8.2
- Apache
- MySQL 8.4
- Docker және Docker Compose
- Git және GitHub

 Негізгі мүмкіндіктері
- Кітапхана туралы ақпаратты көрсету.
- Кітаптар каталогын жасауға негіз дайындау.
- MySQL дерекқорын қолдануға дайындық.
- Docker арқылы веб-сайтты іске қосу.

 Іске қосу
Docker Desktop бағдарламасын іске қосып, терминалда орындаңыз:


docker compose up --build -d


Сайтты ашу: http://localhost:8080

Контейнерлерді тоқтату:


docker compose down


 Қауіпсіздік
Құпиясөздер .env файлында сақталады. Бұл файл GitHub-қа жүктелмеуі керек.
